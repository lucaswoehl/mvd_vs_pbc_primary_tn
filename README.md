# mvd_vs_pbc_primary_tn

This work is currently under peer-review.

The files available in here are meant to support our findings and facilitate the reproducibility of them, so anyone can confirm our estimates and statistical significance. 

The analysis were all coded in R using the *meta* and *metafor* packages in association with the packages to interact with *.csv* files available in the *data* folder.

### Data Privacy

This repository contains no personally identifiable information or individual patient-level data. All data are derived from previously published studies and are provided in an aggregated or de-identified form. No information that could identify individual patients is included.
